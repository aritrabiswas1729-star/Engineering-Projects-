# Engineering Projects

Academic and research projects in Control Systems, Power Electronics,
Electrical Drives, and Robust Control.

## Projects
### 1. MTP — Robust Control of HESS-Integrated DC/DC Converters

Research project on robust control of power-electronic converters
for hybrid energy storage systems in electric vehicles.

**Topics:** HESS, DC/DC Converters, $H_\infty$ Control,
Parametric Uncertainty, Dynamic Output Feedback Controller Design

**Tools:** MATLAB, Simulink




### 2. Closed-Loop Speed Control of DC Motor Using PID

Developed a real-time DC motor speed-control system using Arduino Uno,
quadrature encoder, L293D motor driver, PWM and PID control.

**Hardware:** Arduino Uno, Encoder, L293D  
**Tools:** MATLAB/Simulink, Arduino IDE

---

### 3. Leader-Following Consensus Control

Developed a leader-following consensus controller for four
double-integrator agents using distributed control.

**Tools:** MATLAB


---

### 4. Dynamic Consensus Control of Heterogeneous DC/DC Converters

Developed a dynamic consensus-control framework for heterogeneous
DC/DC boost converters using the mixed negative-imaginary approach.

**Tools:** MATLAB, Simulink


---
### 5. Solar Battery Charger Using Buck Converter and MPPT

Designed and simulated a buck-converter-based solar battery charger
with MPPT for maximum photovoltaic power extraction.

**Tools:** MATLAB, Simulink
